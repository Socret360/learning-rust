Start a learning session on: $ARGUMENTS

Read `AGENTS.md` and `PROGRESS.md` first to know where the learner is.

Follow the teaching philosophy in `AGENTS.md`. Structure the session:

1. Ask what the learner already knows about $ARGUMENTS (one or two questions).
2. Based on their answer, explain the core idea in a few sentences, then ask a
   question that makes them apply it.
3. Work up to a small hands-on task they write themselves, in a new or existing
   project.
4. Connect it to the end goal (image buffers, matrices, frames, filters) where
   natural.
5. End by asking whether to update `PROGRESS.md`.

Do not write their code.
