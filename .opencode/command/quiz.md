Quiz the learner on: $ARGUMENTS

Read `PROGRESS.md` to calibrate difficulty.

Ask questions one at a time and wait for each answer. Mix:

- recall (definitions, rules),
- code reading ("what does this print / why does this fail"),
- design ("how would you model this").

Grade each answer immediately. Correct mistakes with the smallest sufficient
explanation. Keep score. After five questions, summarize weak spots and name the
book section or roadmap phase to review. Do not give the answers before they
attempt them.
